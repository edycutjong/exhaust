# Port of the day-0 spike into the ingot: reproduction and probes (2026-11-15)

- **Toolchain:** `fe 26.6.0 (5b3f96a)`. Newest release on 2026-11-15: v26.6.0 (`gh release list -R argotorg/fe`), so the pin stays.
- **Machine:** Apple M1 Max, macOS (Darwin 25.5.0, arm64). Linux x86-64 rows: `repro-linux-2026-11-15.txt`.
- **Commands** are run from the repository root. Wall times are `/usr/bin/time -p` real seconds, three runs each.

| Check | Result |

| `fe build` (green): `explore(17) == 494`, `explore(CAP) == 609` (CAP = 19), `counterexample(18) == 0`, plus the structural asserts | passes; 0.60 / 0.56 / 0.55 s |

| Bug flip: `git apply demo/refund-after-release.patch && fe build` | exit 1 in 0.36 s; both diagnostics in one build (transcript: `bug-refund-after-release-build.txt`) |
| Revert (`git apply -R …`) | `fe build` green again (0 errors) |

The bug build prints, verbatim:

```
error[3-0036]: assertion failed in const context
   = assertion message: invariant 'paid once' broken: buyer and seller both paid
error[8-0081]: static assertion failed
    ┌─ src/escrow_explore.fe:162:15
162 │ static_assert(counterexample(18) == 0)
    = left: `11234`
    = right: `0`
```

`11234` = Deposit, Deposit, Lock, Release, Refund (legend: 1 Deposit, 2 Lock, 3 Release, 4 Refund, 5 Dispute).
