Why Fe

Take Fe out and the checker is gone.

const fn + whilearray writesstatic_assertassert! messagesenum + matchcontract · msg · recvfe test · 2 backendsfe fmt --check

Since Fe 26.1.0 a const fn can loop and write arrays under static_assert. The search is ordinary Fe; the build is the checker.
